# ADR-025 — Remove Metadata preserves appearance: normalize orientation, preserve ICC

**Status:** Accepted  
**Date:** 2026-08-31

## Decision

For `image.remove-metadata`:

- EXIF Orientation must not be removed in a way that changes visible orientation;
- if orientation metadata is needed to display pixels correctly, the implementation must normalize the pixels before removing the orientation tag;
- non-visual EXIF/XMP/IPTC/textual metadata is removed where the source/output format permits;
- ICC/color-profile information is treated as visual color-management data and preserved when representable;
- pixel dimensions remain unchanged except for the width/height swap implied by a 90°/270° orientation normalization;
- animated/multi-frame inputs remain outside MVP.

## Why

A privacy action must not visibly rotate photographs or alter color merely because technically those facts are stored in metadata containers.
