# ADR-015 — MVP processing queue is sequential

Status: **Accepted**

## Decision

Use a single-consumer `IJobQueue` implementation for MVP processing jobs.

## Rationale

Image processing can be memory and IO intensive. SmartDrag's MVP prioritizes predictable resource use, cancellation, and stability over parallel throughput.

## Consequence

The interface remains abstract so bounded concurrency can be introduced later without changing action contracts.
