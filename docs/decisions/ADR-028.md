# ADR-028 — Overlay authorization and accepted commit decisions are unforgeable capability objects

**Status:** Accepted  
**Date:** 2026-08-31

## Decision

`PreparedOverlaySession`, `OverlayPreparationResult`, and `ActionCommitDecision` have constructors internal to `SmartDrag.Orchestration`.

External Windows/UI adapters may receive and pass these objects but cannot construct a fake prepared session or an `Accepted` commit decision through normal typed code.

The offered ActionId set is stored in an immutable/frozen collection, and the preflight qualification used as authorization evidence is not exposed publicly.

## Why

If adapters could instantiate `Accepted` decisions or mutate authorization data, the commit gate would be a convention rather than an enforceable architecture boundary. Future code should make bypasses difficult by construction.
