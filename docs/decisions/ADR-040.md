# ADR-040 — Application-facing production APIs expose capabilities, not runtime internals

**Status:** Accepted  
**Checkpoint:** Foundation v0.9

## Context

Direct access to JobQueue, DragWorkflow, ActionExecutor, or CompletionCommandExecutor would let future UI code bypass safety gates.

**Decision:** `ProductionRuntimeGraph` exposes only `IProductionDragInteraction`, `MvpPresentationCoordinator`, payload snapshot creation, and capability snapshots. Production commit does not accept an `OutputPolicy`; it uses the MVP output-policy factory.
