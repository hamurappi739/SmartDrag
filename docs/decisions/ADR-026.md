# ADR-026 — Image execution requires content inspection and configurable resource limits

**Status:** Accepted  
**Date:** 2026-08-31

## Decision

The extension allowlist is only a pre-overlay hint. Before full decode/encode, a concrete codec adapter must inspect file contents and report format, dimensions, frame count, and relevant metadata facts.

`MvpImageExecutionGuard` rejects:

- failed/unknown inspections;
- formats outside static JPEG/PNG input MVP;
- multi-frame input;
- invalid dimensions;
- configured source-size, dimension, or decoded-pixel limits.

Numeric limits are not hard-coded into Core/Imaging. G3 benchmarks choose them and composition/configuration supplies them.

## Why

A renamed file is not trustworthy evidence, and unbounded decode can turn a small compressed file into excessive memory/CPU usage.
