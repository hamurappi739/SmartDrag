# ADR-016 — Outputs commit from SmartDrag-owned temporary artifacts

Status: **Accepted**

## Decision

Processors write to a SmartDrag-owned temporary artifact first. The output manager commits it with a non-overwriting move only after the processor reports success.

## Mandatory properties

- source is preserved;
- temporary path is distinct from source/final;
- collision is checked again at commit;
- overwrite=false is mandatory;
- cancellation/failure invokes cleanup.
