# ADR-039 — MVP operation progress is indeterminate until a truthful codec progress contract exists

**Status:** Accepted  
**Checkpoint:** Foundation v0.9

## Context

Elapsed time, input size, or arbitrary timers do not provide a trustworthy processing percentage.

**Decision:** Queued/Running/Cancelling are projected with indeterminate progress. Numeric percentages are forbidden until processor-specific progress reporting is designed and validated. Measured size savings after completion are allowed because they use actual metrics.
