# ADR-041 — MVP settings are validated centrally and cannot disable source preservation

**Status:** Accepted  
**Checkpoint:** Foundation v0.9

## Context

Settings values cross UI/configuration boundaries and can otherwise destabilize overlay behavior or weaken file safety.

**Decision:** `MvpSettingsPolicy` validates bounded timing/placement values and requires `PreserveSource=true`. `MvpOutputPolicyFactory` is the only production MVP path from settings to output policy. Bounds are engineering guardrails and may be tuned later through evidence.
