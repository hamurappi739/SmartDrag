# ADR-038 — Toolkit-neutral presentation state is a separate project

**Status:** Accepted  
**Checkpoint:** Foundation v0.9

## Context

SmartDrag needs user-visible state after the native drag ends, but the overlay UI toolkit is intentionally undecided until Windows proof.

**Decision:** `SmartDrag.Presentation` projects immutable operation/completion snapshots and serializes user intents without referencing WPF, WinUI, HWND, OLE, filesystem implementations, or codecs. Native drag overlay authorization remains in Orchestration.

**Consequence:** a later UI implementation binds to stable presentation contracts instead of becoming the runtime authority.
