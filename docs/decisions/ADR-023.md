# ADR-023 — A shown overlay is an authorization snapshot, not just UI state

**Status:** Accepted  
**Date:** 2026-08-31

## Decision

When an overlay is prepared, SmartDrag captures an immutable `PreparedOverlaySession` containing:

- drag-session identity;
- the preflight qualification that authorized presentation;
- the exact ActionIds offered to the user;
- the rendered overlay model.

A Drop may create an `ActionRequest` only when:

1. the OLE payload is authoritative and supported;
2. its normalized path matches the preflight path;
3. the selected ActionId was actually offered by that overlay session;
4. the action is still available for the authoritative payload/capabilities;
5. the output policy preserves the source.

## Why

This prevents stale UI, forged/unexpected action identifiers, changed capabilities, and preflight/Drop identity races from bypassing product safety rules.
