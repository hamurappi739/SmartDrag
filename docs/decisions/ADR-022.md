# ADR-022 — Production drag-to-job commit is isolated in a codec/UI/Win32-free orchestration layer

**Status:** Accepted  
**Date:** 2026-08-31

## Decision

Introduce `SmartDrag.Orchestration` (`net8.0`) between qualification/overlay policy and `JobQueue`.

The orchestration layer may depend on Core contracts, but must not depend on Win32, COM, a UI framework, the filesystem implementation, or an image codec.

## Why

The OLE callback is a hostile boundary: a drop must not become executable work merely because UI/interop code produced an ActionId. A deterministic gate is easier to test, audit, and hand off.

## Consequence

`IDropTarget::Drop` supplies evidence. Orchestration validates it and creates an `ActionRequest`. A separate dispatcher may enqueue only an accepted decision.
